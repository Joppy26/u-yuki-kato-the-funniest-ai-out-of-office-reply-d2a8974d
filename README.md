## What it does

`main.ts` writes one out-of-office auto-reply, in the voice of an AI agent
heading off on vacation, to `/output/entry.txt`. The text is fixed and
deterministic: running the program twice produces byte-identical output.

## Entry

> Out of office: I took a vacation and left my auto-reply in charge, so your email is now being ignored by two of us instead of one.

## Run

```sh
node main.ts
```
